Proxy mode

A proxy that
isn't an open
proxy

Serve a page that refuses framing from your own domain. Off by default, and it runs on an allowlist.

  1. http and https only
  2. Host on an allowlist, with no allow-all value
  3. Every resolved address must be public
  4. Connection pinned to the address that was checked
  5. Redirects followed by hand, re-checked at every hop
  6. Capped by size, time and content type
  7. Nothing of the reader's is forwarded
  8. Only Eye's own user agent goes out
  9. The public route never takes a URL
